# Uforberedt Foredrag

Dette prosjektet er satt opp med React, TypeScript og Vite direkte i den eksisterende prosjektmappen.

## Kom i gang

Installer avhengighetene:

```bash
npm install
```

Start utviklingsserveren:

```bash
npm run dev
```

Bygg for produksjon:

```bash
npm run build
```

Forhåndsvis produksjonsbygget lokalt:

```bash
npm run preview
```
